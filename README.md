# Catch The Turtle Game

Python dilinde bulunan Turtle kütüphanesi ile yaptığım Catch The Turtle oyunun kaynak kodlarını bu repoda paylaşıyorum.

Kullanmak için repoyu indirip veya kodları kopyalayıp bir IDE'de çalıştırmanız yeterli. Kütüphaneler python'ın dahili kütüphanelerindendir.
